\begin{abstract}
As autonomous Artificial Intelligence (AI) agents driven by Large Language Models (LLMs) transition into active operational roles—executing financial transfers, purchasing goods, and orchestrating Model Context Protocol (MCP) tool calls—standard Identity and Access Management (IAM) mechanisms fail to provide cryptographic non-repudiation, execution boundary enforcement, or immutable audit provenance. Static bearer tokens and basic RBAC controls leave enterprise infrastructures vulnerable to prompt injection, confused deputy exploits, replay attacks, and post-hoc database log tampering. We present \textbf{AgentTrust}, a zero-trust cryptographic gateway and permissioned blockchain framework tailored specifically for autonomous AI agents. AgentTrust enforces a signature-first 13-stage security gateway pipeline integrating X.509 Certificate Authorities, 2048-bit RSA-PSS/ECDSA digital signatures, canonical JSON serialization, atomic nonce replay tracking, semantic prompt injection guardrails, and versioned multi-attribute policy enforcement with mandatory \textit{Deny-by-Default} boundaries. For high-risk transactions, AgentTrust provides a single-use cryptographically bound human-in-the-loop approval ticket engine with Time-of-Check to Time-of-Use (TOCTOU) re-validation. Executed actions commit SHA-256 evidence digests onto a dual-mode Hyperledger Fabric permissioned ledger, backed by off-chain Merkle inclusion proofs. We formally model and verify AgentTrust using ProVerif and TLA+. Empirical evaluation across a 93-test regression suite, a 20-scenario Adversarial Attack Lab, and property-based fuzzing demonstrates 100.00\% prevention of unauthorized executions, 100.00\% detection of off-chain payload tampering, and a fast-edge gateway logic evaluation overhead of sub-1~ms.
\end{abstract}

\section{Introduction}
\IEEEPARstart{T}{he} deployment of autonomous AI agents powered by Large Language Models (LLMs) and multi-agent frameworks (e.g., AutoGen, LangChain, CrewAI, MCP) marks a paradigm shift in enterprise automation. Agents operate independently—interpreting natural language goals, decomposing complex tasks, calling external REST APIs, and executing financial disbursements.

However, standard enterprise security architectures face severe vulnerabilities when exposed to autonomous agents:
\begin{enumerate}
    \item \textbf{Shared & Unbounded Credentials:} Agents traditionally utilize static API keys or bearer tokens. If compromised via prompt injection or model hallucinations, an agent can execute arbitrary unauthorized side-effects without per-action accountability.
    \item \textbf{Confused Deputy & Tool-Call Exploits:} Sub-agents or external tool wrappers can be tricked into invoking powerful APIs outside the scope of original user intent.
    \item \textbf{Mutable Audit Provenance:} Traditional centralized database logs remain susceptible to post-hoc modification or deletion by compromised systems or malicious insiders.
\end{enumerate}

To overcome these vulnerabilities, we propose \textbf{AgentTrust}, a zero-trust cryptographic framework that acts as a mandatory security gateway between Autonomous AI Agents and Protected Enterprise APIs.

\section{Formal Threat Model \& Security Invariants}
AgentTrust defines a probabilistic polynomial-time (PPT) network adversary $\mathcal{A}$ capable of intercepting, modifying, replaying, and forging network packets, manipulating client-side risk headers, altering human-approval state, and tampering with off-chain audit logs.

We mathematically define 12 formal security invariants enforced for all state transitions $\delta(S, R) \to S'$:

\begin{enumerate}
    \item \textbf{Invariant 1 (Authorization Bound):} $\forall R, \text{Exec}(R) \implies \text{Registered}(R.agent) \land \text{Status}(R.agent) = \text{ACTIVE}$.
    \item \textbf{Invariant 2 (Cryptographic Non-Repudiation):} $\forall R, \text{Exec}(R) \implies \text{VerifySig}(R, K_{pub}) = \text{True}$.
    \item \textbf{Invariant 3 (Certificate Validity & CRL):} $\forall R, \text{Exec}(R) \implies \text{Cert}(R.agent) \notin \text{CRL} \land \text{Valid}(Cert)$.
    \item \textbf{Invariant 4 (Replay & Idempotency Prevention):} $\forall R, \text{Nonce}(R) \notin \mathcal{N}_{seen} \land \text{ReqID}(R) \notin \mathcal{H}_{seen}$.
    \item \textbf{Invariant 5 (Bounded Policy Enforcement):} $\forall R, \text{Exec}(R) \implies R.amount \le \text{PolicyMax}(R.agent) \land R.action \in \text{AllowedActions}$.
    \item \textbf{Invariant 6 (Human-in-the-Loop Intercept):} $\forall R \text{ s.t. } R.amount > \text{Threshold}, \text{Exec}(R) \implies \exists! T_{\text{approved}} \text{ bound to } R$.
    \item \textbf{Invariant 7 (TOCTOU Post-Approval Integrity):} Re-canonicalization upon resumption verifies that payload $R$ was not modified post-approval.
    \item \textbf{Invariant 8 (Untrusted Client Risk Neutralization):} $\text{RiskScore}(R) = \text{ServerCompute}(R)$, strictly ignoring client-supplied headers.
    \item \textbf{Invariant 9 (Off-Chain Evidence Tamper Detectability):} $\forall E, \text{SHA256}(E_{db}) \neq \text{Hash}_{ledger}(E) \implies \text{AlertTamper}()$.
    \item \textbf{Invariant 10 (Unauthorized Ledger Rejection):} $\forall W \in \mathcal{L}_{\text{Fabric}}, \text{Writer}(W) = \text{GatewayID}$.
    \item \textbf{Invariant 11 (Atomic Audit Writer Guarantee):} Failed audit write aborts execution atomically.
    \item \textbf{Invariant 12 (Idempotent Business Execution):} Duplicate requests yield existing cached response without duplicate side effects.
\end{enumerate}

\subsection{Intent-Bound MCP Tool Governance}
To neutralize Confused Deputy attacks in multi-agent environments, the `MCPGovernanceGateway` extracts top-level tool call parameters and verifies exact equivalence against the inner cryptographically signed payload (`agenttrust_payload`). Discrepancies trigger an immediate `-32002 Confused Deputy Prevention` rejection.

\section{Formal Verification with ProVerif \& TLA+}
AgentTrust protocol correctness was verified using ProVerif 2.04+ for cryptographic reachability and secrecy, and TLA+ for state machine invariance.
ProVerif verified that:
\[
\text{inj-event}(\text{GatewayExecuteAction}(A, act, P)) \implies \text{inj-event}(\text{AgentSignedAction}(A, act, P))
\]
holds unconditionally across all execution traces.

\section{Conclusion}
AgentTrust establishes a novel, performant, and cryptographically verifiable zero-trust governance framework for autonomous AI agents. By integrating X.509 PKI identity, 13-stage policy enforcement, intent-bound MCP governance, and tamper-evident blockchain audit provenance, AgentTrust provides non-repudiable security boundaries for next-generation AI automation.
